# Python Seminar

Work on the Python exercises in your browser with GitHub Codespaces. You do not need to install Python or an IDE.

## Get started
1. Sign in to Github and open the seminar template repository.
2. Click **Use this template → Open in a codespace**. Wait for the environment to finish setting up the first time.
3. `01-karel-the-robot/student.py` opens for editing. Change only the commands inside `main()` or add your own functions like `turn_right()` and `turn_around()` if you want.
4. Open the **Karel window** preview. If it does not open automatically, contact the teacher.
5. In the Karel window, click **Run Program**. After changing `student.py` click **Reset World** and then **Run Program** again.

If Karel was closed, choose **Terminal → Run Task → Run Karel** in Codespaces.
