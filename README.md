# Python Seminar

Work on the Python exercises in your browser with GitHub Codespaces. You do not need to install Python or an IDE.

## Get started
1. [Read the Karel challenge instructions on GitHub](https://github.com/SamyGinhoven/Python-Seminar/blob/main/01-karel-the-robot/README.md). Keep that page open in a seperate winow tab so you can refer to it while coding. The README is not very readable inside a codespace.
2. On this repository's GitHub page, click **Use this template → Open in a codespace**. The first setup may take a few minutes.
3. If asked whether you trust the folder, click **Trust Folder & Continue**.
5. Two files should open `01-karel-the-robot/student.py` for editing, and `01-karel-the-robot/run_world.py` which is needed to run the program. Change only the commands inside `main()` of `student.py` or add your own functions like `turn_right()` and `turn_around()` if you want.
6. The Karel desktop should open in another browser tab. If your browser blocks it, click **Preferences** in the message at the top of the browser and choose **Allow pop-ups and third party redirects for ...**.
7. when having `01-karel-the-robot/run_world.py`, click the **triangle** (**Run Python File**) in the top right of the editor. This starts the Karel world.
8. In the Karel window, click **Run Program**. After changing `student.py` click **Reset World** and then **Run Program** again.

If Karel was closed, choose **Terminal → Run Task → Run Karel** in Codespaces.
