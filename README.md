# Python Seminar

Work on the Python exercises in your browser with GitHub Codespaces. You do not need to install Python or an IDE.

## Get started
1. Sign in to Github and click **Use this template → Open in a codespace**. The first setup may take a few minutes.
2. If asked whether you trust the folder, click **Yes, I trust the authors** (or **Trust Folder & Continue**).
4. Read the README.md which opens automatically for the challenge instructions. Open `01-karel-the-robot/student.py` for editing. Change only the commands inside `main()` or add your own functions like `turn_right()` and `turn_around()` if you want.
5. The Karel desktop should open in another browser tab. If your browser blocks it, click **Preferences** in the message at the top of the browser and choose **Allow pop-ups and third party redirects for ...**.
6. `01-karel-the-robot/run_world.py` should open as well. Click the **triangle** (**Run Python File**) in the top right of the editor. This starts the Karel world.
7. In the Karel window, click **Run Program**. After changing `student.py` click **Reset World** and then **Run Program** again.

If Karel was closed, choose **Terminal → Run Task → Run Karel** in Codespaces.
